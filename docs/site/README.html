Qualcomm repository map¶

Explore the ecosystem map, choose a repository, and follow its nearby views. Relationship tables explain each arrow and link its source evidence. The generated site works directly from index.html without a server.

Folders¶

  • .generated/ — Contains map views generated from the shared dataset.

  • contributing/ — Owns map editing, exports, and generator reference documentation.

  • .templates/ — Supplies the generated browser entry point and map navigation.

Files¶

  • README.md — Introduces the map and documentation navigation.

  • conf.py — Configures Sphinx, Python reference extraction, and local browsing.

  • Makefile — Owns local and CI setup, generation, and validation commands.

  • requirements.txt — Pins the documentation packages.

  • requirements.lock — Locks direct and transitive documentation dependencies for reproducible builds.
